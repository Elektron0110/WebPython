# Alexis Web Platform

Веб-платформа **Alexis** — многофункциональное веб-приложение на Python/Flask, предоставляющее различные сервисы и инструменты для пользователей.

## 📋 Описание проекта

Проект представляет собой комплексную веб-платформу с следующими основными возможностями:

- **Личный кабинет пользователя** — регистрация, авторизация, управление профилем
- **Сервис отслеживания авиарейсов** — интеграция с FlightRadar24 API для мониторинга полётов
- **Сервис отслеживания поездов** — информация о железнодорожных маршрутах
- **Метеонаблюдения** — визуализация данных с датчиков температуры, влажности и давления через MQTT брокер
- **Мониторинг солнечной активности** — специализированный сервис наблюдений
- **Файловый обменник** — загрузка и скачивание файлов партнёров
- **Библиотека литературных произведений** — каталог текстов
- **Система тестирования** — прохождение тестов (MBTI, смысловые тесты)
- **Встроенная почтовая система** — обмен сообщениями между пользователями
- **WebDAV сервер** — доступ к файловой системе через протокол WebDAV
- **Интеграция с Яндекс.Алисой** — голосовой навык для поиска информации о рейсах
- **MAX мессенджер** — интеграция с MAX платформой для обмена сообщениями

## 📦 Установка

### Требования

- Python 3.10 или выше
- pip (менеджер пакетов Python)

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd <project-directory>
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте необходимые файлы конфигурации:
```bash
# Файл с секретным ключом
echo "your-secret-key-here" > Site/secret.helpfile

# Файл со стартовым значением
echo "1" > Site/start.helpfile

# Файлы для IP фильтрации
touch Site/static/not_blocked_ips
touch Site/static/blocked_ips

# JSON файлы для авторизации
echo "{}" > Site/auth.json
echo "{}" > Site/last.json
```

4. Инициализируйте базу данных (при первом запуске создаётся автоматически):
```bash
cd Site
python Site.py
```

## 📊 Структура базы данных

Проект использует SQLite с несколькими базами данных:

### Site.db (Основная база)

- **AuthUser** — данные аутентификации (email, password)
- **UserInfo** — профиль пользователя (ФИО, телефон, дата рождения, MBTI)
- **Applications** — заявки пользователей

### Mail.db (Почта)

- **MUsers** — пользователи почты
- **MMess** — сообщения почты

### AlexMess.db (AM)

- **AUsers** — пользователи AM системы
- **AMesses** — сообщения AM системы

## 🔧 Дополнительные компоненты

### WebDAV сервер

Встроенный WebDAV сервер предоставляет доступ к файловой системе через стандартный протокол WebDAV. Поддерживает:

- Просмотр директорий
- Загрузку/скачивание файлов
- Управление файлами (создание, удаление, переименование)

### MQTT Брокер (метеоданные)

Компонент для сбора и визуализации данных с датчиков:
- Температура
- Влажность
- Давление

Данные сохраняются в файлы формата JSON и визуализируются через интерактивные графики Plotly.

### Интеграция с Яндекс.Алисой

Навык для голосового поиска информации об авиарейсах:
- Распознавание номеров рейсов
- Информация о статусе рейса
- Данные о местоположении, скорости, высоте

### MAX Мессенджер

Асинхронный клиент для интеграции с платформой MAX:
- Получение и отправка сообщений
- Кеширование имён пользователей
- История сообщений
